# Santa RP Bot

## Arquivos
- bot.py — bot principal com /id começando no 84
- requirements.txt — dependências
- .env.example — exemplo da variável do token
- .gitignore — protege arquivos locais
- santa_ids.json — criado automaticamente quando o bot usar /id
- santa_money.json — criado automaticamente pela economia
- santa_data.json — criado automaticamente pelos dados gerais

## Railway / Render
Use Python 3.10+ e o comando de início:
python bot.py

Configure DISCORD_TOKEN nas variáveis de ambiente.
Edite os IDs de cargos/categoria/canais no início do bot.py.
